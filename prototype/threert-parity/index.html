The geometry and camera translate almost verbatim. The proof is in the headless probe: a stand-in Table Mountain bound to ThreeRT's own SceneBinding produced 15 objects, 11 materials, an atmosphere sky and a 90,000 lux sun — with zero code changes to the scene-graph style.

citylit todayThreeRT equivalentstatus

What does not survive a straight port: GLSL shaders (dissolve, atmosphere rings, globe rim), the screen-space sprite markers/labels, UnrealBloomPass, and all shadow-map / PMREM setup. Those are deleted or rewritten as WGSL material functions — or kept in the PWA layer.

    Worth pursuing as an asset-baking step first. The scene API is compatible enough that one diorama can target both renderers. The biggest payoff is physical time-of-day and rain lighting — the core of citylit's pitch — but that only arrives with the native client. Keep the PWA as the WebGL fallback; don't replace it.

    This prototype verified scene binding only. The missing piece is a real path-traced still: install Rust and use threert-render render ... --spp 32, then diff against captureGalleryShots().
